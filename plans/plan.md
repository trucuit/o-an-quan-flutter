# O An Quan Game in Flutter

## Overview
This project delivers a premium, highly aesthetic, and smooth implementation of the traditional Vietnamese board game **Ô ăn quan** (Mandarin Square Capturing) using Flutter. It features a responsive layout, a dark/light neumorphic or modern card design with smooth animations for stone distribution, particle/sound effects (simulated or actual), local two-player mode, AI player mode, and interactive tutorials.
