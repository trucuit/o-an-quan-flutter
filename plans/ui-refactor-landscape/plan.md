# UI Refactor Landscape & UX Polish

## Overview

This plan details the steps required to transition the O An Quan game's UI to a full-screen, landscape-first design. We will replace text-heavy elements with recognizable icons, maximizing the screen real estate for the game board. 

Additionally, we apply the `ui-ux-pro-max` guidelines for app interfaces: ensuring touch targets (≥44pt) are respected, standardizing the spacing system (4/8dp scale), enforcing correct accessibility labels (for the newly introduced icons), avoiding emoji-based icons in favor of vector (SVG/IconData), and verifying proper contrast ratios and layout stability across device types.
